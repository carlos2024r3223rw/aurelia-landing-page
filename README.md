# Aurelia - Cosmética de Autor

Bienvenido al repositorio de **Aurelia**, una elegante *landing page* para una marca de cosmética de autor. Este proyecto ha sido diseñado para transmitir una estética premium y minimalista, utilizando una cuidada paleta de colores (tonos tinta, marfil, oro y vino) que reflejan sofisticación y lujo.

## 🌟 Características
- **Diseño Premium y Moderno:** Interfaz pulida, inspirada en las últimas tendencias de diseño web, con microinteracciones sutiles que mejoran la experiencia de usuario.
- **Responsive Design:** Completamente adaptable a diferentes tamaños de pantalla (dispositivos móviles, tablets y escritorios).
- **Animaciones CSS:** Efectos visuales fluidos, como gotas, ondas y un sutil "pool glow", creados con CSS puro.
- **Sin Dependencias Externas:** Desarrollado utilizando únicamente HTML5, CSS3 y Vanilla JavaScript, lo que garantiza tiempos de carga ultrarrápidos y fácil mantenimiento.

## 📂 Estructura del Proyecto

El proyecto está compuesto por tres archivos principales para una separación de intereses limpia:

- `landing page.html`: La estructura semántica del sitio y contenido principal.
- `style.css`: Hojas de estilo organizadas con variables globales para facilitar la personalización de la paleta y tipografías.
- `script.js`: Lógica ligera para el menú de navegación, observadores de intersección (scroll reveal) y simulación del formulario.

## 🚀 Cómo empezar
Simplemente clona el repositorio o descarga los archivos y abre `landing page.html` en tu navegador preferido. Si deseas utilizar un servidor local para probarlo de manera óptima, puedes usar herramientas como `npx serve` o la extensión *Live Server* en tu editor de código.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3 (Variables nativas, CSS Grid & Flexbox)
- Vanilla JavaScript (Intersection Observer API)
